Use this guide for hosted 8Labs services. Start with the task you need.

## Find the right panel

- **[Client Panel](https://my.8labs.id)** handles product orders, service accounts, payments, and invoices.
- **[Cloud Panel](https://cloud.8labs.id)** handles server runtime controls and authorized collaboration.

Open your purchased service in Client Panel to find its management link. Do not assume both panels use the same password.

## Get connected

1. [Order and find your server](/docs/getting-started/intro/).
2. [Choose SSH, RDP, or the browser console](/docs/getting-started/accessing-virtual-labs/).
3. [Understand the server workspace](/docs/servers/overview/).

## Manage a running server

- [Power and busy states](/docs/servers/power/) — stop safely before considering force controls.
- [Network addresses](/docs/servers/network/) and [firewall rules](/docs/servers/firewall/) — understand the path before changing it.
- [Backups](/docs/servers/backups/) and [snapshots](/docs/servers/snapshots/) — choose the right recovery point.
- [Telemetry and activity](/docs/servers/telemetry/) — distinguish observations from missing data.
- [Reinstall and deletion](/docs/servers/settings/) — review irreversible impact first.
